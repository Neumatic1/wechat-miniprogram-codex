# GitHub 项目精选小程序 MVP PRD

更新日期：2026-05-20

## 1. 产品目标

打造一款面向开发者的 GitHub 热门开源项目发现小程序，通过日榜、周榜、月榜展示近期 star 增长最快的项目，并提供中文摘要，帮助用户在移动端快速理解项目用途和价值。

MVP 的目标是完成从“发现热门项目”到“阅读中文介绍”再到“收藏或复制链接继续研究”的基础闭环。

## 2. 用户角色

- 普通开发者：每天浏览热门项目，发现新工具、新框架或学习资料。
- 技术负责人：关注技术趋势，为团队选型或调研寻找候选项目。
- 技术内容创作者：寻找近期值得介绍、解读或分享的开源项目。
- 学习者：通过中文摘要降低英文仓库阅读门槛。

## 3. MVP 功能清单

### 3.1 榜单浏览

- 支持日榜、周榜、月榜切换。
- 日榜按约 24 小时 star 增长排序。
- 周榜按约 7 天 star 增长排序。
- 月榜按约 30 天 star 增长排序。
- 日榜每天更新两次，周榜和月榜跟随采集快照刷新。
- 列表展示项目排名、名称、作者、中文摘要、主要语言、当前 star 数、周期 star 增长数。

### 3.2 项目详情

- 展示项目基础信息。
- 展示中文项目介绍。
- 展示项目用途、核心亮点、适用场景。
- 展示 GitHub 原始仓库链接。
- 支持复制 GitHub 链接。
- 支持收藏或取消收藏。

### 3.3 本地收藏

- 用户可以在列表或详情页收藏项目。
- 收藏数据优先存储在小程序本地缓存。
- 收藏不依赖登录。
- 提供收藏列表入口，方便用户回看。

### 3.4 数据更新

- 云函数定时抓取 GitHub 仓库数据。
- 云数据库保存仓库基础信息、star 快照、中文摘要和榜单结果。
- 云函数调用大模型生成中文摘要并入库。
- 小程序前端只读取已整理好的结构化数据。

### 3.5 基础状态处理

- 榜单加载中状态。
- 项目详情加载中状态。
- 无榜单数据空状态。
- 收藏列表空状态。
- 接口失败错误状态。
- 复制链接成功或失败提示。

## 4. 页面结构

### 4.1 榜单页

页面定位：小程序首页，承载主要浏览和发现流程。

核心内容：

- 顶部标题：GitHub 项目精选。
- 榜单切换：日榜、周榜、月榜。
- 更新时间提示。
- 项目列表。
- 收藏入口。

主要操作：

- 切换榜单周期。
- 点击项目进入详情页。
- 收藏或取消收藏项目。
- 下拉刷新当前榜单。

### 4.2 项目详情页

页面定位：帮助用户快速理解单个项目。

核心内容：

- 项目名称和作者。
- 当前 star 数、fork 数、周期增长数、主要语言。
- 中文一句话简介。
- 项目用途。
- 核心亮点。
- 适用场景。
- GitHub 链接。

主要操作：

- 收藏或取消收藏。
- 复制 GitHub 链接。
- 返回榜单页。

### 4.3 收藏页

页面定位：保存用户感兴趣的项目。

核心内容：

- 本地收藏项目列表。
- 项目名称、作者、中文摘要、语言、star 数。

主要操作：

- 点击项目进入详情页。
- 取消收藏。
- 复制 GitHub 链接。

## 5. 主要业务流程

### 5.1 浏览榜单流程

1. 用户进入小程序首页。
2. 小程序默认请求日榜数据。
3. 页面展示加载状态。
4. 数据返回后展示项目列表。
5. 用户切换周榜或月榜。
6. 小程序请求对应榜单数据并刷新列表。

### 5.2 查看详情流程

1. 用户在榜单页点击项目。
2. 小程序进入项目详情页。
3. 小程序根据项目 ID 请求详情数据。
4. 页面展示中文介绍和仓库信息。
5. 用户可收藏项目或复制 GitHub 链接。

### 5.3 收藏流程

1. 用户点击收藏按钮。
2. 小程序将项目基础信息写入本地缓存。
3. 页面更新收藏状态。
4. 用户再次点击可取消收藏。

### 5.4 数据采集流程

1. 定时云函数每天触发两次。
2. 云函数获取候选 GitHub 仓库数据。
3. 云函数写入仓库基础信息和 star 快照。
4. 云函数根据当前快照与历史快照计算日榜、周榜、月榜增长值。
5. 云函数对新增或摘要过期的项目调用大模型生成中文摘要。
6. 云函数将榜单结果和详情数据写入云数据库。

## 6. 数据字段

### 6.1 Repository 仓库基础信息

- `repoId`：GitHub 仓库 ID。
- `fullName`：仓库全名，例如 `owner/name`。
- `owner`：仓库作者或组织。
- `name`：仓库名称。
- `description`：GitHub 原始描述。
- `language`：主要语言。
- `topics`：GitHub topics。
- `stars`：当前 star 数。
- `forks`：当前 fork 数。
- `openIssues`：当前 issue 数。
- `githubUrl`：GitHub 仓库链接。
- `pushedAt`：最近推送时间。
- `createdAt`：仓库创建时间。
- `updatedAt`：记录更新时间。

### 6.2 StarSnapshot star 快照

- `repoId`：GitHub 仓库 ID。
- `stars`：采集时 star 数。
- `capturedAt`：采集时间。
- `source`：数据来源。

### 6.3 RepoSummary 中文摘要

- `repoId`：GitHub 仓库 ID。
- `titleZh`：中文标题。
- `summaryZh`：一句话中文简介。
- `whatItDoes`：项目用途。
- `highlights`：核心亮点列表。
- `useCases`：适用场景列表。
- `generatedAt`：摘要生成时间。
- `summaryVersion`：摘要结构版本。

### 6.4 Ranking 榜单结果

- `rankType`：榜单类型，取值为 `daily`、`weekly`、`monthly`。
- `repoId`：GitHub 仓库 ID。
- `rank`：排名。
- `starGrowth`：当前周期 star 增长数。
- `stars`：当前 star 数。
- `calculatedAt`：榜单计算时间。

### 6.5 LocalFavorite 本地收藏

- `repoId`：GitHub 仓库 ID。
- `fullName`：仓库全名。
- `summaryZh`：一句话中文简介。
- `language`：主要语言。
- `stars`：收藏时 star 数。
- `githubUrl`：GitHub 仓库链接。
- `favoritedAt`：收藏时间。

## 7. 接口与云函数

### 7.1 小程序调用云函数

- `getRankings`：获取日榜、周榜、月榜列表。
- `getRepoDetail`：获取项目详情。

### 7.2 定时任务云函数

- `syncGithubRepos`：抓取候选仓库并保存快照。
- `generateRepoSummaries`：为新增或需要更新的项目生成中文摘要。
- `calculateRankings`：计算日榜、周榜、月榜结果。

### 7.3 安全要求

- GitHub token、大模型 API key 只保存在云函数环境变量或云端安全配置中。
- 小程序前端不得出现任何密钥、token、私有接口地址。
- 云函数日志不得输出密钥、完整请求头或敏感配置。

## 8. 异常状态

- 榜单为空：展示空状态，引导用户稍后刷新。
- 接口失败：展示错误提示，并提供重试操作。
- 详情不存在：提示项目数据暂不可用。
- 摘要为空：展示仓库原始描述和“中文介绍生成中”状态。
- 复制链接失败：提示用户重试。
- 本地缓存不可用：收藏失败时提示用户稍后再试。

## 9. 非 MVP 功能

- 用户登录。
- 云端收藏同步。
- 个性化推荐。
- 语言、技术方向、topic 分类筛选。
- 趋势曲线和历史增长图。
- 评论、点赞、分享社区。
- 订阅消息推送。
- web-view 内打开 GitHub 仓库。
- 管理后台。
- 付费能力。

## 10. 验收标准

- 用户可以打开首页并看到日榜项目列表。
- 用户可以切换日榜、周榜、月榜。
- 用户可以进入项目详情页查看中文介绍。
- 用户可以收藏和取消收藏项目。
- 用户可以进入收藏页查看本地收藏项目。
- 用户可以复制 GitHub 仓库链接。
- 小程序在加载、空数据、接口失败时有明确状态反馈。
- 前端不包含 GitHub token、大模型 API key 等敏感信息。
- 云函数能够按快照计算日榜、周榜、月榜的 star 增长。
- 中文摘要由云函数生成并入库，前端只读取结果。
