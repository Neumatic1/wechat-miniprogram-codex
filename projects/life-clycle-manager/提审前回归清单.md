# 提审前回归清单

建议使用两台真机或一台真机加一台已清空本地数据的设备完成回归。

## 执行前准备

- [ ] 已部署最新 `lifeCycleSync` 云函数。
- [ ] 已确认云环境、数据库、云存储可用。
- [ ] 测试设备网络正常。
- [ ] 准备 1 张相册图片，便于验证图片同步和替换。

## 核心场景

- [ ] 游客新增物品。
预期：可正常保存，本地首页与详情页展示正常，“我的”页显示当前为本地模式。

- [ ] 登录并同步到云端。
预期：登录成功后当前数据可同步到云端，“我的”页显示最近一次同步成功时间。

- [ ] 新建带图片物品。
预期：真机可成功上传图片并保存；详情页和首页缩略图正常显示。

- [ ] 修改物品并替换图片。
预期：新图片显示正常；再次同步后旧云图片被清理，不再残留。

- [ ] 删除本地数据后从云端恢复。
预期：当前设备数据被清空后，可从云端完整恢复物品、模板和图片引用。

- [ ] 换设备恢复。
预期：第二台设备登录同一微信账号后，可拉取到同一份云端数据。

- [ ] 删除物品。
预期：物品从首页、详情页消失；再次同步后对应云图片被清理。

- [ ] 退出登录再重新登录。
预期：退出后回到本地模式；重新登录后仍可继续同步和恢复。

## 额外关注点

- [ ] 微信开发者工具里如果本地图片上传失败，会弹出“请用真机测试图片同步”的明确提示。
- [ ] “我的”页能清楚看到“最近一次同步成功时间”。
- [ ] “我的”页能清楚看到“当前是否存在未同步的本地修改”。
- [ ] 删除本地数据不会误删云端数据。
- [ ] 从云端恢复前会有覆盖确认提示。
